# Button

Botão principal do design system, utilizado para disparar ações do usuário e navegação.

**Categoria**: Interaction  
**Complexidade**: Simples

## 2. Anatomia
Nomeia as partes do componente com vocabulário compartilhado.

1. **Label** — Texto claro que indica a ação que será executada.
2. **Ícone (Opcional)** — Auxilia na identificação visual da ação.
3. **Container** — Define a área clicável e o estilo visual (variante).

---

## 3. Quando e Como Usar

### ✅ Use quando
- A ação principal da página precisa de destaque (variante default).
- Ações secundárias ou de menor importância (variante outline/ghost).
- Em formulários para submissão de dados ou disparar modais.

### ❌ Não use quando
- A ação é puramente de navegação entre páginas (use o componente Link).
- Existem muitas ações primárias na mesma seção (causa fadiga visual).

### ✍️ UX Writing
| Elemento | Regras de formato | ✅ Correto | ❌ Evitar |
| :--- | :--- | :--- | :--- |
| **Label** | Verbo no infinitivo · máx. 3 palavras | Salvar Alterações | Clique aqui |
| **Confirmação** | Ação específica · sem genéricos | Excluir Conta | Sim / OK |

---

## 4. Do & Don't

### ✅ Faça isso
Diferencie claramente a ação principal das secundárias usando variantes distintas. O olho do usuário deve encontrar o botão primário instantaneamente.

### ❌ Não faça isso
Evite usar múltiplas variantes primárias (default) na mesma seção visual para não criar conflito de atenção.

## 6. Acessibilidade
Recursos implementados para garantir o uso por todos os usuários.

- ✓ Navegação por teclado completa utilizando a tecla `Tab`.
- ✓ Ativação via teclas `Enter` e `Espaço`.
- ✓ Estados de foco visíveis (`focus-visible`) e com alto contraste.
- ✓ Suporte a `aria-label` para botões com ícone único.

---

## 7. Componentes Relacionados
- **ButtonGroup**: Para agrupar ações relacionadas de forma coesa.
- **Link**: Utilize quando a intenção for estritamente navegacional.

---

## 8. Notas e Dicas
- **Ícones**: Se o botão não tiver texto, forneça sempre um `aria-label`.
- **RouterLink**: Use a prop `asChild` para renderizar o botão como um `RouterLink`.

---

## 9. Critérios de Teste
- O evento `@click` deve ser emitido apenas se o botão não estiver `disabled`.
- O visual deve ser consistente em Light e Dark mode (incluindo estados hover).
- O anel de foco deve ser visível na navegação por teclado.
